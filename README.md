## 命名空间

我的理解是限制作用域，防止命名污染的情况。使用规则如下

1. 在查找同名变量时默认先查找局部域。在找全局时前加::，最后用空间命名 + :: 找命名空间中的变量。
2. 命名空间是可以进行合并的，即使是在不同的文件下，因此注意两个子命名空间中不要出现重复变量。
3. 相同的命名空间是可以进行嵌套的，因此会出现在一个大的命名空间内变量相同的情况。

## 缺省函数

函数参数可以拥有默认值，其实就是默认值满足大多数情况，不想再给函数传参设计的。分为全缺省和半缺省。规则如下：

1. 缺省值只能是常量或者是全局变量，因为函数的实现是在全局范围内的。
2. 实现和声明在不同的文件下，在编译时优先识别声明，因此缺省参数，声明必须带缺省，实现可以不带缺失值。
3. 只能从右到左进行缺省，具体原理与汇编代码执行时压栈有关。

## 函数重载

C++为了实现同名函数的充分利用，目的是为了满足实现相同功能的参数类型不同的需要。规则如下：

1. 参数个数，类型，顺序不同都构成函数重载。
2. 返回类型不同，其他都相同的函数不构成函数重载，因为调用时识别不是返回进行识别。
3. 参数名称不构成函数重载，具体原理是编译器只识别类型。
4. 两个类型，参数，返回值都相同的函数，一个给了缺省值，一个没给不构成函数重载。



> 拓展：函数名在进行编译过程中根据不同平台的编译器，最后形成的名称也不同，但调用函数时都是通过地址的形式进行调用的。
